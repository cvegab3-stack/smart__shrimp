# Backend Django

Para desarrollo local en Windows, usa `scripts/run_django_windows.ps1` desde la raíz. La configuración `config.settings.local` guarda datos en SQLite y conecta con M3 en localhost. `manage.py` usa esa configuración si no se especifica otra.

Para instalar dependencias, ejecutar la aplicación, crear el primer supervisor administrador y probar el sistema, sigue los pasos del README principal.
